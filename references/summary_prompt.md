# 月度/批次总结生成提示词模板

以下步骤用于把「已解析的 Markdown 笔记」整理成一份结构化的考前总结。
请在生成前先阅读 `references/section_guide.md` 了解六板块与智能解析规则。

## 输入
- 一个月份（或一批）对应的若干份 `parsed/*.md` 文件内容。
- 科目名称（如「德语 B1」）、月份标签（如「2026 年 7 月」）。

## 操作步骤
1. **逐份速读**每份 Markdown，标注其命中的板块（单词词汇 / 语法 / 听 / 说 / 读 / 写）。
2. **去重合并**：把多份笔记里重复的词汇、句型、模板合并，保留最完整的表述与例句。
3. **按板块组织**：严格按「单词词汇 → 语法 → 听 → 说 → 读 → 写」顺序撰写。
4. **智能省略**：某个板块在本批中无任何内容，直接不写该板块标题与内容。
5. **⚠️ 易错标注**：从原文抓取错误，用引用块标出（见 section_guide）。
6. **给出速记提示**：每个板块结尾用 1~3 句话点出「考前最容易考 / 最容易错」的要点。

## 输出格式（Markdown）
```
# {科目}{月份}笔记总结

> 覆盖文件：{文件1}、{文件2}…（共 N 份）
> 生成日期：{YYYY-MM-DD}

## 单词词汇
（按主题分组的 vocab 表；无则整段删除）

## 语法
（语法点 + 例句 + ⚠️易错；无则整段删除）

## 听
（无则整段删除）

## 说
（无则整段删除）

## 读
（无则整段删除）

## 写
（写作模板 + 扣分点 + ⚠️易错；无则整段删除）
```

## 转为 Word 文档
把上面这份 Markdown 用 `scripts/build_docx.py` 渲染成 `.docx`（AI 自动执行，用户无需敲命令）：
```bash
python3 scripts/build_docx.py --input summaries/{月份}.md --output final/{月份}笔记总结.docx
```
- 用 python-docx 渲染：标题层级、列表、表格、`**粗体**`/`*斜体*` 内联；
  **⚠️ 易错小节整段标黄高亮**，醒目便于考前避坑。
- **不依赖 WorkBuddy 内置 skill**，任何能跑 Python 的 AI 工具都能出 Word。
- 输出路径约定：`final/{月份}笔记总结.docx`（如 `final/7月笔记总结.docx`）。

## 无日期文件的单独提炼
若本批包含无日期的通用素材，单独产出 `final/{科目}基础素材提炼.docx`，
结构同上，但覆盖文件标注为这些无日期文件。
